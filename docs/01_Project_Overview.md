# NetSentinel

## Intelligent Network Port Scanner & Service Analysis Dashboard

### Vision

NetSentinel is a Flask-based web application designed to scan hosts, discover open ports, identify running services, maintain scan history, generate security insights, and provide an intuitive dashboard for network administrators, students, and cybersecurity enthusiasts.

The application aims to simplify network reconnaissance while presenting the results in an organized and interactive dashboard.

---

## Objectives

- Scan TCP ports
- Detect common services
- Store scan history
- Generate reports
- Visualize network statistics
- Provide basic security recommendations
- Export reports

---

## Target Users

- Students
- Network Administrators
- System Administrators
- Cybersecurity Learners
- IT Support Engineers
